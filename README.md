## Requirements

**Windows**
- 64-bit Windows 10 or higher.
- [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe).
- GPU supporting OpenGL 3.3 with latest drivers installed.

Earlier versions of Windows may work but are not tested.

**Linux**
- 64-bit distro with glibc 2.34 or newer — e.g. Ubuntu 22.04+, Debian 12+, Fedora 35+, or RHEL/Rocky/AlmaLinux 9+.
- X11 or Wayland session (Wayland is supported natively; X11/XWayland also works).
- GPU supporting OpenGL 3.3 with latest drivers installed.

Older distros (Ubuntu 20.04, Debian 11, RHEL 8, etc.) are not supported due to glibc version.

**macOS**
- macOS 14 (Sonoma) or higher on Apple Silicon (arm64).
- macOS 13 (Ventura) or higher on Intel (x86_64).
- GPU supporting OpenGL 3.3 with latest drivers installed.
